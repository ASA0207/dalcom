# 🍓 달콩 | DALKONG

성인 친목 디스코드 서버 달콩의 GitHub Pages 홈페이지.

## 배포
ZIP 압축을 풀어 `index.html`과 `assets/` 폴더를 저장소 최상위에 업로드하세요. Settings → Pages → Deploy from a branch → main / root.

## 기능
- 입장 전 무음, 입장 클릭/Enter 후 Teddy Bear BGM 재생 (볼륨 18%)
- 음악 재생/정지/음소거/볼륨 조절, 다크 모드, 공유, 궁합 테스트, 랜덤 메시지
- 키보드로 `asa` 입력하면 화려한 ASA 이스터에그 (닫기 버튼 또는 Esc)
- 달 아이콘 5회 클릭으로도 비밀 화면 실행
- 모바일 반응형 / 모션 감소 설정 지원

## 참고
초대 링크는 제공되지 않아 임의로 삽입하지 않았습니다. 음악을 공개 배포할 때는 저작권자의 이용 허락을 확인하세요.
