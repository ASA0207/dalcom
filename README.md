# 달콤 공식 소개 페이지 🍓

## GitHub Pages 배포
1. GitHub에서 새 공개 저장소를 만듭니다.
2. `index.html` 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
4. Branch: `main`, Folder: `/(root)`로 저장합니다.

## 주요 기능
- 시작 화면 및 Enter 입장
- 반응형 파스텔 UI, 다크 모드
- 배경 파티클, 스크롤 등장 애니메이션
- 4문항 궁합 테스트, 오늘의 메시지
- 달 클릭 이스터에그(5번), `dalkom` 키보드 이스터에그
- 소리 버튼으로 선택적으로 켜는 효과음(외부 음원 불필요)
- 공유 및 소개 복사

## 수정 안내
`index.html`을 텍스트 편집기로 열어 규칙 및 문구를 변경하세요.
초대 링크는 제공되지 않아 넣지 않았습니다.
규칙 4번은 원문이 비어 있어 별도의 규칙을 창작하지 않았습니다.
